## Flagship Project — mydailyroutine.app

> Live AI-powered daily planner SaaS — built solo, shipped in 1 month, 5 active users

| | |
|---|---|
| **Live** | [mydailyroutine.app](https://mydailyroutine.app) |
| **Stack** | Next.js App Router · TypeScript · MongoDB · Redis · Paddle · Gemini AI · Coolify VPS |
| **Auth** | Dual auth — NextAuth v5 (Google OAuth) + custom JWT via `jose` (email/password + OTP) |
| **Payments** | Paddle one-time checkout with HMAC-SHA256 webhook verification + deduplication |
| **Infrastructure** | Self-managed Coolify on Hostinger VPS · AWS S3-compatible storage · GitHub Actions CI/CD |
| **Security** | Strict CSP headers · X-Frame-Options · rate limiting · Zod validation on all Server Actions |

**Key features:** Gemini-powered AI routine builder · 7-day drag-and-drop timeline · sync drag across recurring tasks · goal tracking with timeline markers · streak heatmaps · smart reminders
